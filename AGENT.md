# Agent Project Memory: proxmox-gpu-setup-scripts

## Project Overview

Automated setup scripts for Proxmox VE 9.1 based on Debian 13 (Trixie) or later, focusing on GPU passthrough (AMD/NVIDIA) to unprivileged LXC containers.

## Key Components

### 1. Guided Installer (`guided-install.sh`)

- Interactive menu-driven entry point.
- Tracks progress via `.install-progress` file.
- Discovers scripts in `host/` dynamically based on numeric prefix (e.g., `001 - ...`).

### 2. Host Scripts (`host/`)

Run on Proxmox host to configure drivers and create containers.

- **Drivers**: `003-install-amd-drivers.sh`, `004-install-nvidia-drivers.sh`.
- **System**: `001-install-tools.sh`, `007-setup-udev-gpu-rules.sh` (udev rules for persistent PCI paths).
- **LXC Creation**: `031-create-gpu-lxc.sh` handles container creation, GPU mapping, and user config.

### 3. LXC Scripts (`lxc/`)

Run inside the created LXC containers.

- **Docker + Drivers**: `install-docker-and-amd-drivers-in-lxc.sh`, `install-docker-and-nvidia-drivers-in-lxc.sh`.
- **Applications**: `install-rocm-llamacpp-in-lxc.sh` (specific support for local LLMs on AMD).

## Implementation Details

- **GPU Passthrough**: Uses PCI paths for persistence (e.g., `/dev/dri/by-path/...`) via udev rules generated by `007`.
- **Unprivileged Containers**: Setup maps `/dev/dri`, `/dev/kfd` (AMD), or NVIDIA devices with appropriate cgroup permissions.
- **State Management**: `guided-install.sh` checks for completion markers or auto-detects based on system state (installed packages, loaded modules).
